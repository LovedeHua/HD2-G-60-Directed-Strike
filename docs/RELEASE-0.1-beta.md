# 0.1 beta

First public beta of HD2 G-60 Smart Targeting, based on development build 0.5.19.

G-60 ignores ordinary small bugs, prioritizes supported Terminid heavies and assigns only one grenade per target.
Mark a supported bug hole, Shrieker Nest, Spore Spewer or objective egg sack to redirect a grenade there first.

Download `HD2-G60-Smart-Targeting-0.1-beta.zip` for installation. The source ZIP is for development.
Requires Bingus Shared Loader API 1 with addon discovery (v15+). Disable older G-60 copies before deploying.

Enemy behavior and ordinary/large hole explosions have gameplay confirmation. Eggs and tower destruction still need separate confirmation.
This beta retains native compatibility guards and experimental lifetime status. See the README for scope and limitations.

## 繁體中文

第一個公開 beta，使用開發版 0.5.19 的相同遊戲程式。
G-60 會忽略一般小怪，依順位追蹤指定重型單位，同目標只分配一顆手雷。
自己標記支援的蟲洞、飛龍巢、孢子菇或任務蟲卵後，已飛出的手雷也能優先轉向。

請下載模組 ZIP 匯入管理器，停用舊版後重新部署。原始碼 ZIP 不是安裝包。
怪物功能及普通／大型蟲洞爆炸已經實測；蟲卵與高塔破壞效果仍待確認。
