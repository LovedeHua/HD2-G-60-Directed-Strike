# Changelog

## 0.1 beta.1

- Make diagnostic logging optional: missing log service, open failures and write/flush/close failures no longer block the addon.
- Runtime version 0.5.20. Targeting policies, native compatibility checks and ownership checks retain their existing behavior.
- Added portable logging regressions and an assembled-entry Windows check. No new live-game test is claimed.

## 0.1 beta

First public beta, based on development build 0.5.19.

- Heavy-enemy whitelist, priority ordering and one-grenade-per-target reservations.
- Tuned attack points and approach routes for supported Terminid heavies.
- Local marked-structure override for normal/large bug holes, Shrieker Nests, Spore Spewers and objective egg sacks.
- Mark memory, arrival-controlled detonation and expiry removal.
- Reproducible standalone source build, test fixtures and 16:9 / 4:3 promotional covers.

The deployment payload is unchanged from the tested development build. Earlier internal version numbers are not public release numbers.
