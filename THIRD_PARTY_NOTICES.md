This is an unofficial community mod, not an official Arrowhead or Sony product.

The addon integrates with [Bingus Shared Loader](https://github.com/CowboyBingus/BingusSharedLoader), which is installed separately.
It uses LuaJIT's FFI on the Windows x64 runtime; no LuaJIT or loader binary is bundled.
Compatibility files contain checked signatures and numeric/model-derived data needed for interoperability.
Full game images, disassemblies, asset payloads and proprietary DLLs are excluded from the repository.

Cover images were edited with OpenAI's built-in image generation tool from the author's gameplay video.
The existing C4 and Grenade Contact Detonation covers guided the graphic style. See `docs/ARTWORK.md` for provenance.
